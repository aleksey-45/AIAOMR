# 小计划：把符头判据做对（几何节奏收尾）

> 承接 `2026-10-18-aiaomr-v3-p2.md` 任务 2。任务 2 的原型已提交（`e3f5f3a`、`e87bc9c`、`06e221f`），
> 但真页面对照 0/7，空心符头判据在合成图上没验过。这份小计划只做"符头 + 时值"这一段。

## 要做什么

让几何节奏在打上花火第一系统上至少 5/7 个小节给出确定的时值序列，其中二分/全音符靠
符头的"空心"判据，四分/八分靠符干 + 连梁/符尾。做完再把几何时值接进装配，替换模型读的时值。

## 为什么这样做

任务 2 的真图对照结果是 0/7：几何能找出符干，但二分音符被当成四分，加起来对不上拍号，
整小节退回 `unknown`。旧项目在空心符头上失败过三次，说明"看起来像"不够，必须有可复现的
判据和真图样本。所以第一步不是改算法，是**先拿真图裁出四个样本**（实心符头、空心符头、
附点、符尾），把判据的回归基线立起来。

## 硬约束

1. 不引入新依赖；`cv2`（opencv-python-headless）已经在装好。
2. 阈值一律 deg 倍数，禁止绝对像素（R-03）。
3. 判据只返回 `Finding`（kind/value/bbox/evidence），不直接改 IR；装配在 `locate/rhythm.py`。
4. 空心/实心判不准的符头标 `unknown`，不许猜。
5. 先写失败测试，再实现；真图样本进 `tests/fixtures/`，不许只靠合成图。

## 任务

### 1. 真图样本（半天）

从打上花火第一页裁四个小图存进 `tests/fixtures/heads/`：

- `filled_quarter.png`：一个四分音符的符头；
- `hollow_half.png`：一个二分音符的符头（注意谱线穿过它，这是关键难点）；
- `dot.png`：一个附点；
- `flag.png`：一个符尾。

再写 `tests/fixtures/heads/manifest.json`，记每个图的原图坐标和期望类别。测试只读这些文件，
不依赖网络和外部路径。

### 2. 修 HeadCriterion 的洞判定（半天）

现在的问题：判洞前先抹谱线行，空心符头的圆环被切开，`RETR_CCOMP` 数不到洞。

改法：在符头包围盒的**局部窗口**里处理——先把窗口内的谱线行抹掉、再补上被抹掉的
左右边界（用列方向的连通性），然后数洞；或者反过来，在**原始图**上判洞、只在找连通域时
才抹谱线。两条都试，选在四个真图样本上都对的那条。

测试：`test_hollow_half_is_hollow`、`test_filled_quarter_is_filled`、`test_dot_is_not_a_head`、
`test_flag_is_not_a_head`。

### 3. 模板自举 + NCC（半天）

不再手写形状阈值。对每个候选符头取 `deg` 归一化后的灰度块，按 bbox 大小聚类，取每类
medoid 当模板；用 `cv2.matchTemplate(..., TM_CCOEFF_NORMED)` 给每个候选打分，与"洞判据"
交叉验证：两者一致才采纳，不一致标 `unknown`。

模板不落盘，每次从本页自举（同一份刻谱符头只有两三种形状），避免外部字体依赖。

### 4. 接进节奏装配（半天）

`locate/rhythm.py` 里，对每根符干找最近的符头：

- 空心 + 有符干 → `half`；
- 空心 + 无符干 → `whole`；
- 实心 → 走现在的连梁/符尾规则（四分/八分/十六分/三十二分）；
- 找不到符头的符干 → `unknown`。

附点仍用 `DotCriterion`；`BeanShape.evidence` 里记 `head_class` 和模板得分，报警/终裁引用。

### 5. 真页面对照门（半天）

跑打上花火第一系统，和 `打上花火/read/sys01.json` 的 `dur` 字段逐拍比：

- deterministic 小节数 ≥ 5/7 且逐拍一致；
- 过不了就停在这一步，不改装配，回头查判据；不许靠调 `expected_ticks` 放水。

### 6. 小范围接线 + 复验（一天）

通过后接进 read/assemble：几何时值与模型 beat 数量一致时，用几何时值覆盖模型时值（prov 记
`derived`，evidence 带几何来源）；数量不一致时把该小节标 `unknown`、发 A8 候选报警，交复读。

重跑打上花火第一页，看 A1 从 11 条降到多少，写出 gp5 后跑审计。四首的复验仍留给 P2 任务 11。

## 做的顺序和门

任务 1 → 2 → 3 是判据本身，必须全部通过才做 4；任务 5 是门，不过就停；任务 6 是接线，
接线后指标必须比接线前好，否则回退。

## 不做的事

- 不做 A8 的数字模板（那是 P2 任务 6 的事，这里只留接口）；
- 不做多声部、跨小节连梁；
- 不换模型、不引深度模型、不碰 GPU。
