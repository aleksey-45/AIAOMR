# AIAOMR v3 P2 实施计划：把节奏读对，把报警处理掉

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

## 这份计划要做什么

P1 把第 3 类输入从一张图跑到了写出闸门，但四首歌全部停在 `E_BUILD_VALIDATE`：小节时值对不上拍号，四首的 A1 报警是 36 / 36 / 3 / 7 条，写出校验拒绝产出 `.gp5`。同时 A2 音高在补参考信息之后已经不响了，骨架调号用窄图问法也定住了（打上花火：B 大调）。

P2 就两件事：

1. **把节奏从模型手里拿回来**：用几何量符干、符尾、附点、连音线，每拍的时值由几何给候选，模型只负责认音符（弦号 + 品数）和复核。这是旧项目 `rhythm.py` 干的活，v3 在 P1 里丢了，现在补回来。
2. **让报警有出口**：补 A6–A12，接上复读与终裁（盲读），报警不再攒到写出闸门。

做完之后，同样的四首歌要能写出 `.gp5`、通过往返核对与 alphaTab 审计，并且第一次把 0.90 / 0.95 两个验收阈值真正量出来。

## 为什么这样排

P1 的失败顺序很清楚：先卡节奏，再卡写出，最后没有任何指标。

所以先改写出闸门的边界（任务 1）：小节时值对不对是 A1 报警的事，不该由 writer 的 validate 来阻断。这一步不改识别质量，但能把流程打通、把指标量出来，后面每一步才有可比数字。

然后是几何三件套（任务 2、3、4）：节奏、连音、多小节休止。这三件互相咬合——没有连音，节奏会把连音后半当成独立音符；没有多小节省止，整首曲子的编号会错位。

复读与终裁（任务 5）必须排在几何之后：不然模型报的三百条噪音会全部触发复读，钱花了，问题还是那些。补全 A6–A12（任务 6）同理，先把能确定的东西确定下来，再让终裁去处理真正拿不准的。

并发（任务 7）、缓存（任务 8）、语料门（任务 9）放在最后，是因为它们不影响识别质量，只影响成本和迭代速度；等识别链路稳定了再做，测试也才有意义。

## 必须遵守的硬约束

1. P1 的全部硬约束继续有效（Python 3.10、依赖白名单、不碰 GPU、图片只能放 user 消息、JSON 模式、前缀稳定、重试只带截断摘要、原子写、两条流、cp936、预算按每 8 小节）。
2. **几何只出候选，不出结论**：几何给的时值、连音、多小节休止都要能在报警里被推翻；写进 IR 之前必须过 A1/A3/A4/A8/A9。
3. 几何里所有阈值以 deg 为单位，禁止绝对像素常量（沿用 R-03）。
4. 复读必须盲读：请求里只带报警规则与 claim/expected，不许带上一次的读数（AD-01）。
5. 终裁最多 `adjudicate.max_rounds = 2` 轮；终裁记录写进 `judgements[]`，含模型名、prompt 版本、时间（AD-04）。
6. **写出闸门只管"能不能写"**：时值名、dots、弦号、品数、文本编码、beat 结构。小节时值合计属于 A1 报警，不由 writer 阻断。
7. 报警不阻断；硬停仍然只有三类：输入不可用、预算超限、写出的文件在结构上表达不了。
8. 任何一项读不出来就兜底并记来源，不许因为缺一项整首失败（沿用 §2.2）。
9. 不许为了让测试变绿放宽断言、改阈值、删测试；阈值只有任务 11 能按规范的例外流程调整。

## 评审重点：五类最容易咬人的情况

第一，**几何节奏在真谱上不一定灵**。旧项目自己就踩过空心符头（三次尝试失败），四/五线混排、连音线压在符干上、复调声部都会让符干检测出错。测试里必须先在合成图上过，再拿打上花火第一系统跟旧项目交付的读数逐拍比对；比对不过就先不接线。

第二，**几何与模型的 beat 数量对不上时怎么办**。几何说这一小节 4 拍、模型说 3 拍，谁错？不许静默选一边。规定：数量不一致 → 整小节进复读；复读还不行 → 终裁；终裁记录里写明两边各自说了什么。

第三，**多小节休止的计数错一位，整首曲子编号全错**。打上花火开头就是 16 小节休止。窄问题读完数之后，必须与"小节宽度 / 休止条长度"的几何估计交叉核对，不一致就报警 A9，不许直接采信。

第四，**复读的独立性**。复读提示里一旦带上第一次的读数，模型就会顺着点头，"两次一致"变成自己跟自己一致。测试要在请求体上断言：复读请求里不含上一次的 reads/结论。

第五，**改完写出闸门之后，别把"内容错"当成成功**。任务 1 会让 P1 那四首歌都能写出 gp5，但它们是错的。验收必须量指标，不能以"能写出文件、审计两项为零"为通过标准。

**对外接口**

**步骤**

- [ ] **4. 实现符尾与连梁。** 相邻音柱之间找粗横线（厚度约 0.5 deg、长度 ≥1.5 deg、位于符干顶端附近）：连梁条数 1/2/3 对应 eighth/16th/32nd。单符干看顶端小钩（flag）：1 个 eighth、2 个 16th。
