# 读五线谱规范（Staff Reading Spec）

> 本文件是 `docs/spec-v3.md` 的配套规范，编号体系相同；与 `spec-v3.md` 冲突时以它为准，本文件只把
> "五线谱怎么读"这一段写到可实现的细度。读者是实现 `score/staff/` 的人、评审和写测试的人。

## 0. 范围

**管什么**：从一张已经定位好的页面图里，读出每个小节的符号类别和拍内时值，并给出
"这一小节确定 / 部分确定 / 不知道"的结论与理由。

**不管什么**：系统与小节定位、谱号区、裁片坐标（`spec-v3.md` §2.1）；拍号、调号、调弦
（§2.2，作为本层输入）；音高、弦号、品位（TAB 与模型，F-01）；送模型、预算、事件流。

本层是 L3 的纯计算：不联网、不调模型、不写业务文件；所有阈值以 deg（谱线间距）为单位，禁止绝对像素（R-03）。

## 1. 术语

| 术语 | 含义 |
|---|---|
| **五线谱带** | 该系统五线谱那一段纵向范围，含符干、横梁、加线所需的余量；不含 TAB 带 |
| **符号** | 一个可独立识别的图形：符头、符干、横梁段、符尾、附点、休止符 |
| **符头** | 音符的圆/椭圆头部，分实心与空心 |
| **符干** | 符头侧面伸出的竖线，朝上或朝下 |
| **横梁段** | 连梁组里一条水平粗线，左右两端各接一根符干 |
| **连梁组** | 由横梁段连起来的一组符干，对应拍内的一个连梁单元 |
| **拍格** | 由拍号推出的小节时间格，4/4 是四个四分格，6/8 是六个八分格（每三格一组成拍组） |
| **拍组** | 刻谱的连梁分组单位：4/4 是一个四分，6/8 是一个附点四分 |
| **tick** | 时间单位：1/32 拍为 1 tick，四分音符 = 8 tick |
| **abstain** | 明确表示"这一拍/这一小节判不了"，不是 `unknown` 时值 |

## 2. 三条铁律

| ID | 规则 |
|---|---|
| **SR-01** | **横向间距禁止用于推断时值或 onset。** 刻谱的横向间距只反映排版美学，与音乐时长无关（实测同一小节里 px/tick 能差一倍）。横坐标只允许用于两件事：谁在谁左边、哪些符号相连 |
| **SR-02** | **拍号与拍格是装配时的隐含条件，不是切图依据。** 禁止按拍格裁图或切割窗口；拍格只用来判断"这个结论成不成立"（§8） |
| **SR-03** | **判不准就 abstain，禁止猜、禁止用和校验反推时值。** 和校验只能否决结论，不能生成结论 |

三条铁律是评审的第一检查项：任何判据里出现"用 x 间距估时长""按拍位切窗""用 sum 反推某个音符时值"都算违规。

## 3. 输入与输出

**输入**：`arr`（整页灰度数组）、`System`（y0/y1、tabY0/tabY1、tabLines、measures）、`MeasureBox`、
`deg`（谱线间距），以及 `Skeleton` 里的 `timeSignatures`（只用于 §8 的隐含条件，不参与 §5–§7 的符号判定）。

**输出**：`MeasureRhythm`（§10），每小节一个。它是**几何侧的 claim**，不是最终结论；最终结论由装配层
把几何 claim 与模型读数合并后给出（§14）。

输出里**禁止**出现音高、弦号、品位、调号判断，也禁止出现"猜测性质的时值"。

## 4. 窗口与预处理

| ID | 规则 |
|---|---|
| SR-10 | 五线谱带 = `[y0 − 4·deg, min(tabY0 − 2, y1 + 4·deg)]`；下界同时不得越过与下一条谱表中点的距离。TAB 带单独建窗口，禁止把 TAB 的符干/横梁并进五线谱判据 |
| SR-11 | **谱线必须按整条线厚抹掉**：线的行范围由定位层给出的 run 决定，前后各加 1 px 抗锯齿余量。禁止只抹中心行——残留的上下边沿会被当成两条横梁（真页面实测：整小节被读成十六分） |
| SR-12 | 预留给符干、横梁的余量：上不少于 3.5·deg、下不少于 3.5·deg（低音谱号贝斯声部通常不超过一条加线） |
| SR-13 | 任何符号在五线谱带边界被截断（符干顶端、横梁、加线、休止符）→ 该拍 `abstain: AR-01`，禁止"补全后再判" |
| SR-14 | 小节窗口左右各留 0.5·deg 余量；符号归属按"符号中心落在谁的窗口"判定，相邻小节共用的边界符干只计一次 |
| SR-15 | 二值化用页面自适应的割点（`adaptive_cut`），禁止固定 128；同一页内所有小节必须用同一个割点 |

## 5. 符号判据

每条判据只回答"这里有没有、有几个、是什么类别"，并给出 `bbox`、置信度和证据；不直接产出时值。
判据之间不得互相读取中间结果以外的状态（顺序：符干 → 横梁/符尾 → 符头 → 附点 → 休止）。

### 5.1 符头（实心 / 空心）

| ID | 规则 |
|---|---|
| SR-20 | 候选：抹谱线、抹符干列之后的连通域，宽 `0.7–1.9·deg`、高 `0.3–1.2·deg`、宽高比 ≥ 1.1 |
| SR-21 | 空心/实心先看**填充率**（连通域面积 / 外接框面积）与**环宽**；阈值由真图样本标定，初始 空心 ≤ 0.55、实心 ≥ 0.75，落在中间 → `abstain: AR-02` |
| SR-22 | 模板复核：从本页自举两类模板（每类取 medoid），`matchTemplate(TM_CCOEFF_NORMED)`；与 SR-21 一致才采纳，不一致 → `abstain: AR-02` |
| SR-23 | 洞判据（`RETR_CCOMP` 数内洞）**只作佐证**。真图上谱线穿过符头内部会把洞切成两半，只数洞会错判；洞的结论与 SR-21 相反时不推翻 |
| SR-24 | 一个连梁组里符头类别应一致（二分音符不与八分音符连梁）；不一致说明配对错了，按 SR-45 处理 |

### 5.2 符干

| ID | 规则 |
|---|---|
| SR-25 | 竖直连续墨迹，长度 `2.0–5.5·deg`，与符头侧边相接；长度超上限通常是相邻谱线的竖线/小节线的误检，丢弃 |
| SR-26 | 符干方向 = 从符头向外的方向；同一连梁组内方向必须一致（SR-44） |
| SR-27 | 符干在带边界被截断 → `abstain: AR-01`（不许按"至少这么长"推断） |

### 5.3 横梁段

| ID | 规则 |
|---|---|
| SR-28 | 水平粗线：在两根符干之间覆盖率 ≥ 0.85，厚度 `0.3–0.9·deg`；两端必须各接一根符干，接不上的段丢弃并记 `AR-12` |
| SR-29 | 按 y 分层：相邻横梁段中心 y 差 > 0.8·deg 视为不同层（符干朝上在头顶、朝下在脚底；两层的 y 带不许混） |
| SR-30 | 一层的横梁段 = 一条连梁线；同一连梁组的相邻层间距应约等于 0.5–0.7·deg，明显偏离说明混进了谱线残留或其他符干 |

### 5.4 符尾

| ID | 规则 |
|---|---|
| SR-31 | 只对**没有横梁**的符干判：符干末端外侧 `2.2·deg × 1.8·deg` 区域内的钩状墨迹，按钩的条数取 1/2/3 |
| SR-32 | 符尾区域必须用抹过谱线的掩码（谱线横穿会整行算成墨迹）；区域墨迹不足下限则不判符尾 |

### 5.5 附点与断音点

| ID | 规则 |
|---|---|
| SR-33 | 附点锚在**符头右侧**（符头中心偏右 `0.6–1.5·deg`、纵向 ±0.6·deg），不再锚在符干底部（符干朝下时会偏） |
| SR-34 | 附点可以是 1 个或 2 个（双附点）；每个附点都是孤立小墨点，面积 `3–0.45·deg²` |
| SR-35 | 断音点画在符头**另一侧**，不算时值；判据必须排除相反侧的小墨点 |
| SR-36 | 休止符的附点同样按 SR-33/SR-34 处理，锚在休止符字形右侧 |

### 5.6 休止符

按三组判，因为它们是三种不同形状：

| ID | 组合 | 规则 |
|---|---|---|
| SR-37 | 全休止、二分休止 | 实心小矩形，宽度 `1.2–2.0·deg`。**只靠挂线位置区分**：全休止挂在第四条线下方，二分休止坐在第三条线上；位置差约 1·deg，必须用谱线行坐标判，禁止按高度猜 |
| SR-38 | 四分休止 | 折线字形；按形状模板判，不作矩形过滤 |
| SR-39 | 八、十六、三十二分休止 | 钩状字形，按钩数 1/2/3 判，和符尾 SR-31 同一套逻辑 |
| SR-39b | 多小节休止条 | 近似贯穿小节宽的粗横线（已有 `RestBarCriterion`）；条数由印刷数字读，属于 §2.2/模型范围，本层只标"这是多小节休止" |

### 5.7 明确不读的记谱

下列符号本层**不识别**，只要在小节内检出/疑似检出，整小节 `abstain: AR-06`，交模型与复读：

连音线（tie/slur 弧线）、三连音数字与括号、装饰音（倚音，含斜线）、双声部（两套独立符干）、
反复记号与跳房子、跨小节连梁、跨谱表的连线。

理由：它们改变的是"时间怎么分"，不是"这个符号多长"；在没有可靠判据前硬判会把错误静默写出去。

## 6. 归属

符头、符干、横梁段分开判完只是零件；节奏型取决于它们的连接关系。

| ID | 规则 |
|---|---|
| SR-40 | 符头–符干配对：取符干根端（与符头相接的一端）最近的符头，距离 ≤ 1.2·deg；一个符干可带多个符头（和弦），同 x 上下排列 |
| SR-41 | 横梁段左端连左符干、右端连右符干，误差 ≤ 0.6·deg；连通块 = 一个连梁组 |
| SR-42 | **组内顺序由横梁段的左右延伸定**：只有右段 = 组首，只有左段 = 组尾，两侧都有 = 中间。刻谱约定：一个连梁组里除最后一个音符外，横梁都向右侧延伸 |
| SR-43 | 每根符干的**横梁条数 = 入射横梁段的条数**，不是"两根符干之间的行数"；混合时值（前八后十六、二级横梁短横）只有按入射段数才判得对 |
| SR-44 | 一组内符干方向必须一致、符头类别必须一致；不一致 → `abstain: AR-04` |
| SR-45 | 同一 x（±0.3·deg）出现两组独立符干/两套连梁 → 判为多声部，`abstain: AR-06` |
| SR-46 | 符头与符干配不上、横梁段端点配不上、组内出现孤立的符干 → 对应拍 `abstain`，不允许"最近邻硬配" |

## 7. 时值判定

判定的顺序是固定的：**符头类别 → 符干有无 → 横梁/符尾条数 → 附点**。

| ID | 条件 | 时值 |
|---|---|---|
| SR-50 | 空心头 + 无符干 | `whole` |
| SR-51 | 空心头 + 有符干 | `half` |
| SR-52 | 实心头 + 有符干 + 横梁/符尾 0 条 | `quarter` |
| SR-53 | 实心头 + 有符干 + 横梁/符尾 1 / 2 / 3 条 | `eighth` / `16th` / `32nd` |
| SR-54 | 休止符按 §5.6 的类别对应 `whole` / `half` / `quarter` / `eighth` / `16th` / `32nd` |
| SR-55 | 附点：1 个 ×1.5，2 个 ×1.75（GP 能表达双附点；三附点判为 `abstain: AR-02`） |
| SR-56 | 一个连梁组内各符干的横梁条数可以不同（混合时值），但**组内 tick 之和必须是整拍组的整数倍**（§8） |
| SR-57 | 整小节没有任何符号、墨迹低于阈值 | 允许判为全休止，证据记 `empty-bar`；这是唯一允许的"推断"，因为它只有一种解释，且 A1 对全休止小节跳过 |

**不存在"时值未知但先填个四分"的中间态**：判不出就是 abstain（SR-03）。

## 8. 组织与和校验

### 8.1 拍格

| 拍号 | 一拍 | 拍组（连梁分组单位） |
|---|---|---|
| 4/4、3/4、2/4 | 四分 | 1 个四分 |
| 6/8、9/8、12/8 | 八分 | 3 个八分（附点四分） |
| 2/2、3/2 | 二分 | 1 个二分 |
| 其他（5/8、7/8、混合拍号、中途换拍的本小节） | — | `abstain: AR-09`，阶段二再支持 |

拍号取该小节生效的那一项（`effective_ts`，中途换拍按事件列表）。拍号缺失 → 整页 `abstain: AR-09`。

### 8.2 隐含条件（只用于发现矛盾，不用于生成结论）

| ID | 条件 | 违反时 |
|---|---|---|
| SR-60 | 连梁组的边界必须落在拍组边界上 | `abstain: AR-04` |
| SR-61 | 按左到右顺序累加各拍 tick，任一点不得超过小节总 tick | `abstain: AR-05` |
| SR-62 | 全部拍累加必须等于该小节拍号（整小节 `unknown` 之外的情况） | `abstain: AR-05`，**禁止**调整某个音符的时值去凑 |

三条是"否决权"：写得出来的结论必须同时满足，否则这一小节不进 `ok`。它们不产生新结论，也不允许按拍位切窗口（SR-02）。

### 8.3 结果状态

| 状态 | 含义 |
|---|---|
| `ok` | 小节内所有拍都判出、满足 §8.2 三条 |
| `partial` | 部分拍判出、其余 abstain；判出的拍仍要满足 SR-61/62 的局部约束 |
| `unknown` | 整小节 abstain |

`partial` 与 `unknown` 都要带 `abstains` 列表，写清原因编号（§9）。

## 9. 不确定的原因编号

| 编号 | 原因 |
|---|---|
| AR-01 | 符号在五线谱带边界被截断 |
| AR-02 | 符号类别不确定（特征与模板不一致） |
| AR-03 | 符头与符干配不上 |
| AR-04 | 连梁图有歧义（组边界不在拍组上、方向/类别不一致） |
| AR-05 | 时值和不等于拍号 |
| AR-06 | 本小节出现本规范不读的记谱（连音线、三连音、装饰音、双声部、反复） |
| AR-07 | 谱线行判定失败（厚度超限或行数不是 5 条） |
| AR-08 | 休止符字形不认识 |
| AR-09 | 拍号缺失或不受支持 |
| AR-10 | 窗口退化（宽或高小于 2·deg） |
| AR-11 | 横梁段端点配不上符干 |
| AR-12 | 配对数超过符干数（重复检测） |

原因编号是**统计口径**：`metrics.json` 里按编号计数（`spec-v3.md` §8.2），用来判断下一步该补哪条判据。

## 10. 数据结构

新增到 `kernel/contracts.py`（只放数据，不放行为；`extra="forbid"`）：

```python
class RhythmBeat(_Model):
    x: float                                  # 原图横坐标，只用于排序与证据
    kind: Literal["note", "rest"]
    duration: Literal["whole", "half", "quarter", "eighth", "16th", "32nd"] | None
    dots: int = 0
    noteCount: int = 1                        # 这一拍上的符头数（和弦 > 1）
    head: Literal["hollow", "filled"] | None  # 休止为 None
    beams: int = 0                            # 入射横梁条数或符尾条数
    group: int | None = None                  # 连梁组编号
    confidence: float = 0.0                   # 0..1，判据给的综合置信度
    evidence: dict = {}

class Abstain(_Model):
    reason: str                               # AR-xx
    measure: int
    beat: int | None = None
    detail: dict = {}

class MeasureRhythm(_Model):
    index: int
    status: Literal["ok", "partial", "unknown"]
    beats: list[RhythmBeat] = []
    abstains: list[Abstain] = []
    ticks: int = 0                            # 仅 status == "ok" 时有意义
    deg: float = 0.0
```

`confidence` 不是给模型看的，是给"要不要把这一拍标成争议点"用的（§14）；禁止用它做加权平均或软判决。

## 11. 参数

全部登记进 `spec-v3.md` §5 的参数表；代码里禁止出现表外魔数。初始值待真图样本标定，
**改动必须在报告里写清"改了哪个值、哪张样本、前后各错几拍"**，禁止为了让测试变绿改阈值。

| 参数 | 初始 | 说明 |
|---|---|---|
| `staff.band_margin_deg` | 4.0 | 五线谱带上下余量（SR-10/SR-12） |
| `staff.measure_margin_deg` | 0.5 | 小节窗口左右外扩（SR-14）；只作上下文，符号归属按中心落在小节框内判 |
| `staff.line_erase_pad_px` | 1 | 抹谱线时的抗锯齿余量（SR-11） |
| `staff.head_w_deg` | 0.7–1.9 | 符头宽度范围 |
| `staff.head_h_deg` | 0.3–1.2 | 符头高度范围 |
| `staff.head_fill_hollow_max` | 0.55 | 填充率低于此为空心 |
| `staff.head_fill_filled_min` | 0.75 | 填充率高于此为实心；中间 abstain |
| `staff.template_ncc_min` | 0.75 | 模板匹配采纳下限 |
| `staff.stem_len_deg` | 2.0–5.5 | 符干长度范围 |
| `staff.beam_coverage` | 0.85 | 横梁段覆盖率下限 |
| `staff.beam_thickness_deg` | 0.3–0.9 | 横梁段厚度范围 |
| `staff.layer_gap_deg` | 0.8 | 横梁分层 y 差阈值 |
| `staff.beam_gap_deg` | [0.5, 4.5] | 相邻符干的水平间距区间（deg）；超出即不算同一条横梁 |
| `staff.beam_attach_tol_deg` | 0.6 | 横梁段端点"接到符干"的容差（deg，SR-41） |

## 12. 目录、文件与产物归属

本层是新目录 `score/staff/`（`spec-v3.md` §1.6 已登记）。**一个文件只拥有一类判据**；
`read.py` 只做编排，不放判据、不放阈值。新增文件必须在本节登记一行，否则 code review 视为违规。

### 12.1 源码

```

├── base.py         # Finding / Criterion 底座（判据的公共接口）
```

## 13. 测试与验收

### 12.1 单元

每条判据至少一个正例、一个反例，合成图与真图样本各一份。真图样本放 `tests/fixtures/heads/`，
`manifest.json` 记原图坐标、期望类别、来源小节；测试只读这些文件（离线）。

### 12.2 交叉表门（样本集）

| 组 | 门 |
|---|---|
| 全、二（空心头） | 召回 100%，且不把实心判成空心 |
| 四（实心头） | 召回 100% |
| 八、十六、三十二 | 横梁条数全对 |
| 休止三组 | 全休止/二分休止靠挂线位置全对 |
| 附点 | 不漏、不把断音点当附点 |

**硬门：`二分 → 四分` 这一格必须为零。** 它是旧项目失败次数最多的一类。

### 12.3 真页面门

打上花火第一系统（printed 16–22）：

- `ok` 小节数 ≥ 5/7（第一阶段），最终目标 7/7；
- `ok` 的小节每一拍时值与 `打上花火.gp5` 一致；
- 判不准的必须落在 `partial`/`unknown`，**不允许"猜对"**（猜对的样本要单独统计，算缺陷不算成绩）；
- 反例回归：真页面 m18 曾因谱线残留把整小节读成十六分（SR-11）；空心符头的洞被谱线切断（SR-23）；附点锚在符干底部导致漏判（SR-33）。

### 12.4 确定性与可复现

同输入两次运行结果必须逐字段一致；模板自举必须确定（medoid 取法固定，禁止随机初始化、禁止 k-means）。

## 14. 与其他层的接缝

| 接缝 | 规则 |
|---|---|
| → 装配（L3） | 几何结论是 claim。与模型读数**数量与时值都一致**时，用几何的（prov 记 `derived`，evidence 带几何来源）；不一致时该小节标争议点、发 A8 候选报警，交复读 |
| → 验算（L3） | `MeasureRhythm` 不参与 A1–A9 的判定；A1 仍以最终 IR 为准。几何结论只作为 A8 的输入 |
| → 评测（非层） | `ok` 小节的正确率、`abstain` 原因分布写进 `metrics.json` |
| ← 骨架（L3） | 只读 `timeSignatures` 用作 §8 的隐含条件；调号/调弦/速度与本层无关，禁止读取 |
| ← 定位（L3） | 只读 `System`/`MeasureBox`/`deg` 与谱线行范围；不得自己重新定位系统 |

报警不阻断：几何结论缺失或矛盾只是把该小节变成争议点，流程继续。
